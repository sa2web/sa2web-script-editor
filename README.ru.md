# Sa2web Plugin Editor

Sa2web Plugin Editor — настольный редактор полных плагинов сайтов sa2web. Он позволяет редактировать настройки и скрипты с подсказками `api.` в Monaco, проверять их на развёрнутом сайте и экспортировать JSON.

## Отладка на сайте

1. В развёрнутой панели sa2web откройте страницу **Plugins** нужного сайта. Создайте плагин с тем же именем, что в редакторе, и выпустите **токен отладки**. Храните его в секрете.
2. Введите в редакторе то же **имя плагина** и **токен**, а также HTTP(S) **тестовый URL** сайта. Измените настройки и скрипты; черновик сохраняется локально.
3. Нажмите **Launch**. В новом окне при необходимости войдите под учётной записью администратора. Cookie сохраняются для следующих запусков.
4. Когда окно откроет `/app/index`, редактор синхронизирует черновик с плагином, у которого совпадают имя и токен. При несовпадении появится ошибка; при успехе в окне на пять секунд появится уведомление.
5. Проверяйте сайт в этом окне. Отладочная конфигурация доступна только сеансу с токеном; остальные посетители её не загружают. После изменений снова нажмите **Launch**.

## Экспорт плагина

Укажите **имя**, **версию** (`ver`) и **описание** (`remark`), затем нажмите **Export**. JSON содержит метаданные, настройки и скрипты.
