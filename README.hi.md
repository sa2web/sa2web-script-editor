# Sa2web Plugin Editor

[English](README.md) · [简体中文](README.zh.md) · [Español](README.es.md) · [Français](README.fr.md) · [हिन्दी](README.hi.md) · [Bahasa Indonesia](README.id.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Русский](README.ru.md) · [Tiếng Việt](README.vi.md)

Sa2web Plugin Editor, sa2web साइट प्लगइन के लिए डेस्कटॉप संपादक है। Monaco में `api.` सुझावों के साथ कॉन्फ़िगरेशन और स्क्रिप्ट संपादित करें, तैनात साइट पर परीक्षण करें और प्लगइन JSON निर्यात करें।

## ऑनलाइन डीबगिंग

1. तैनात sa2web प्रबंधन मंच पर साइट का **Plugins** पेज खोलें। संपादक में उपयोग होने वाले नाम से प्लगइन बनाएँ और **डीबग टोकन** जनरेट करें। टोकन सुरक्षित रखें।
2. संपादक में वही **प्लगइन नाम**, **टोकन** और साइट का HTTP(S) **परीक्षण URL** दर्ज करें। कॉन्फ़िगरेशन और स्क्रिप्ट संपादित करें; ड्राफ्ट स्थानीय रूप से सहेजा जाता है।
3. **Launch** दबाएँ। नई विंडो में आवश्यक होने पर साइट व्यवस्थापक खाते से लॉग इन करें। कुकी बनी रहती हैं, इसलिए अगली बार सामान्यतः फिर लॉग इन नहीं करना पड़ता।
4. नई विंडो के `/app/index` पहुँचने पर समान नाम और टोकन वाले प्लगइन में ड्राफ्ट सिंक होता है। गलत नाम या टोकन पर त्रुटि दिखती है; सफलता संदेश पाँच सेकंड तक उसी विंडो में दिखता है।
5. उसी विंडो में साइट का परीक्षण करें। डीबग कॉन्फ़िगरेशन केवल टोकन वाली सत्र को मिलता है; अन्य आगंतुकों पर प्रभाव नहीं पड़ता। बदलाव के बाद फिर **Launch** दबाएँ।

## प्लगइन निर्यात

**नाम**, **संस्करण** (`ver`) और **विवरण** (`remark`) दर्ज करके **Export** दबाएँ। JSON में मेटाडेटा, कॉन्फ़िगरेशन और स्क्रिप्ट शामिल हैं।
