# Sa2web Plugin Editor

[English](README.md) · [简体中文](README.zh.md) · [Español](README.es.md) · [Français](README.fr.md) · [हिन्दी](README.hi.md) · [Bahasa Indonesia](README.id.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Русский](README.ru.md) · [Tiếng Việt](README.vi.md)

Sa2web Plugin Editor는 sa2web 사이트 플러그인 전체를 편집하는 데스크톱 앱입니다. Monaco의 `api.` 자동 완성을 사용해 설정과 스크립트를 작성하고 배포된 사이트에서 테스트한 후 JSON으로 내보낼 수 있습니다.

## 온라인 디버깅

1. 배포된 sa2web 관리 화면에서 해당 사이트의 **Plugins** 페이지를 엽니다. 편집기에서 사용할 이름으로 플러그인을 만들고 **디버그 토큰**을 생성합니다. 토큰을 안전하게 보관하세요.
2. 편집기에 동일한 **플러그인 이름**과 **토큰**, 해당 사이트의 HTTP(S) **테스트 URL**을 입력합니다. 설정과 스크립트를 편집합니다. 초안은 로컬에 저장됩니다.
3. **Launch**를 클릭합니다. 새 창에서 필요한 경우 사이트 관리자 계정으로 로그인합니다. 쿠키가 유지되므로 다음 실행에는 보통 다시 로그인할 필요가 없습니다.
4. 새 창이 `/app/index`에 도달하면 이름과 토큰이 일치하는 플러그인으로 초안을 동기화합니다. 불일치하면 오류가 표시되고 성공하면 새 창에 5초 동안 알림이 표시됩니다.
5. 그 창에서 사이트를 테스트합니다. 디버그 설정은 토큰이 있는 세션에만 적용되며 다른 방문자는 로드하지 않습니다. 수정 후 다시 **Launch**를 클릭하세요.

## 플러그인 내보내기

**이름**, **버전**(`ver`), **설명**(`remark`)을 입력하고 **Export**를 클릭합니다. JSON에 메타데이터, 설정, 스크립트가 포함됩니다.
