# Sa2web Plugin Editor

[English](README.md) · [简体中文](README.zh.md) · [Español](README.es.md) · [Français](README.fr.md) · [हिन्दी](README.hi.md) · [Bahasa Indonesia](README.id.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Русский](README.ru.md) · [Tiếng Việt](README.vi.md)

Sa2web Plugin Editor は sa2web サイトプラグイン全体を編集するデスクトップアプリです。Monaco の `api.` 補完を使って設定とスクリプトを編集し、デプロイ済みサイトで動作確認して JSON を書き出せます。

## オンラインデバッグ

1. デプロイ済み sa2web の対象サイトで **Plugins** ページを開き、エディターと同じ名前のプラグインを作成して**デバッグトークン**を発行します。トークンは安全に保管してください。
2. エディターに同じ**プラグイン名**と**トークン**、サイトの HTTP(S) **テスト URL** を入力します。設定とスクリプトを編集します。下書きはローカルに保存されます。
3. **Launch** をクリックします。新しいウィンドウで必要に応じてサイト管理者としてログインします。Cookie は保持され、通常は次回のログインが不要です。
4. 新しいウィンドウが `/app/index` に到達すると、名前とトークンが一致するプラグインに下書きを同期します。不一致はエラーになり、成功時はそのウィンドウに５秒間通知が表示されます。
5. そのウィンドウでサイトをテストします。デバッグ設定はトークンを持つセッションだけに適用され、他の利用者には読み込まれません。変更後は再び **Launch** をクリックします。

## プラグインのエクスポート

**名前**、**バージョン**（`ver`）、**説明**（`remark`）を入力して **Export** をクリックします。JSON にはメタデータ、設定、スクリプトが含まれます。
